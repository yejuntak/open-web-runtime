# Clean-room implementation policy

Open Web Runtime is an independent implementation of a general web-agent runtime.

Contributors must not copy proprietary TinyFish source code, private prompts, internal protocols, models, assets, non-public documentation, or hosted-service trajectories into this project.

Public product behavior may be used only as a high-level interoperability requirement. Implementation must come from independently written code, public browser standards, or properly licensed open-source dependencies.

Every adapted open-source snippet must retain the license obligations of its source and should record the upstream project and revision in `THIRD_PARTY.md`.

Evaluation should use independent public benchmarks and project-owned fixtures rather than competitor-generated traces.
